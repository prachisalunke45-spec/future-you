# Future You - Career Discovery Website

An interactive website that helps students discover a career path based on their interest.

## Live Demo
https://prachisalunke45-spec.github.io/future-you/

## Features
- Enter your name
- Pick an interest: Coding, AI, Design, Cyber Security or Gaming
- Choose your level
- Get a suggested career path, a future score and a 30-day mission

- HTML
- CSS
- JavaScript
